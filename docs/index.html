From library to fighter

Build the moveset you have in mind.

01 / INSPECT

See what you select

Browse your extracted clips and preview their source skeleton or retargeted character mesh. Import compatible character models from local files.

02 / REPLACE

Know what changes

Readable move names, command inputs, and a current-to-replacement comparison help you choose the right VF action.

03 / CONNECT

Give moves follow-ups

Create strings and branches. Set inputs, transition timing, hit frames and damage, then keep the design in a reusable JSON recipe.

Run on your own machine

A local workflow.
Your own assets.

Download or clone the source, install Python dependencies, and connect your prepared asset library, VF template and converter workspace.

The source release does not include game files, keys, Blender binaries or EF-12 vendor tools. A prepared workspace is required; this is not a one-click installer.

Read the setup guide ↗
git clone https://github.com/KuroRaiden/Budokai-to-EF12.git
cd Budokai-to-EF12
python -m pip install -r requirements.txt
python configure.py
python studio.py

With the prepared workspace configured, open http://127.0.0.1:8765. Select a move, start a string, and add follow-ups.

Project status

Built to experiment. Ready to tune.

What has been checked

Structural tests and native exports passed. Combo recipes preserve branches and timing. Generated action, command and animation references have been checked in an exported pack.

What still needs a playtest

In-game combo timing, collisions, hit behavior and compatibility need validation. Preview plays one clip at a time. AI, physical controller remapping, beam effects and separate RB Ki charging are not generated.
